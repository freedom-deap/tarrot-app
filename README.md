# Tarot Reading

大・小アルカナを使った、ブラウザ向けのタロット占い・カードゲームアプリです。外部ライブラリなしのHTML、CSS、JavaScriptで動作します。

## 起動方法

`index.html`をブラウザで開きます。ローカルHTTPサーバーを利用する場合は、プロジェクトのルートで次のように起動できます。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## データの編集

- カード情報：`js/data.js` の `majorCards` と `minorCards`
- スプレッド情報：`js/data.js` の `spreads`
- カード裏面：`img/card-back.svg`（このプロジェクトで作成）

起動時に `img` ディレクトリ内のカード表面22枚と裏面画像を事前に読み込みます。画像名とカードの対応は `js/data.js` で管理し、読み込めない画像がある場合は画面と開発者コンソールに通知します。ブラウザからディレクトリの内容を直接列挙することはできないため、新しい画像を追加するときは同ファイルのカード定義にもパスを追加してください。

大アルカナの意味は `js/data.js` の `majorNames` に定義します。小アルカナは同ファイルの `minorCardMeanings` に56枚分の入力欄があり、各カードの `upright`（正位置）と `reversed`（逆位置）に意味を3つずつ記入できます。カード名はスート名と数字・人物札の名前から生成します。

占い開始時には登録されている大アルカナ22枚をすべて裏向きで表示してシャッフルし、山札から選択したスプレッドに必要な枚数だけを取り出します。

```js
"minor-wands-01": {
  upright: ["", "", ""],
  reversed: ["", "", ""]
}
```

小アルカナの意味はスートと数字・人物札から合成せず、カードごとに表示します。補足説明は `minorSuits` の `meaning` と `minorRanks` の `meaning` に記入します。`minorRanks` にはエース、2～10、ペイジ、ナイト、クイーン、キングを1件ずつ定義しているため、各値の `meaning` を個別に編集できます。補足は正逆共通で、小アルカナのカードを開いたときだけカード固有の意味の下に表示されます。未入力の欄は「意味は後から設定します。」と表示されます。

## 占いとカードゲーム

TOPページではスプレッドを選ぶ前に、スリーカード・二者択一に小アルカナを含めるか選択できます。ワンカードは大アルカナのみです。カードゲームはスプレッドとは別枠のリンクから開きます。

- `poker.html`：CPUとの5枚交換ポーカー。小アルカナ56枚に、毎回ランダムに選ぶ異なる大アルカナ2枚をワイルドなジョーカーとして加えます。交換は最大3枚、1回です。スートに強弱はなく、ファイブカードも役に含みます。
- `blackjack.html`：小アルカナ56枚でディーラーと対戦します。エースは1点または11点、数字札はその数、コート札はすべて10点です。ディーラーは17点以上で止まります。

## 画像の出典と利用条件

アプリ画面の「画像の出典・利用条件」から `credits.html` を開けます。表示しているカード表面78枚と裏面1枚の情報は `image_sources.json` に保存されています。小アルカナ56枚の取得時メタデータは `minor_arcana_images/minor_arcana_sources.json` にあります。

画像を入れ替えた場合は出典データを更新し、`python build_credits.py` で一覧ページを再生成してください。大アルカナの画像はWikipediaから取得された縮小版で、取得時のファイル版までは記録されていません。
